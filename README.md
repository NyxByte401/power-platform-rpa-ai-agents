# RPA e Agentes de IA | Microsoft Power Platform

## Sobre o projeto

Portfólio de documentação técnica sobre desenvolvimento de automações RPA e experimentação com agentes de inteligência artificial utilizando o ecossistema Microsoft Power Platform.

O conteúdo apresenta competências práticas em desenvolvimento de fluxos modulares, automação de interfaces, integração com aplicações, depuração, testes e configuração de agentes de IA.

## Tecnologias

- Microsoft Power Automate Desktop
- Microsoft Copilot Studio
- Microsoft Excel
- Microsoft Power Platform
- Robotic Process Automation (RPA)
- Inteligência Artificial Generativa

## Experiência técnica

**Automação RPA:** desenvolvimento de fluxos no Power Automate Desktop, organização em subfluxos, integração com Excel, manipulação de arquivos e depuração de problemas de execução.

**Agentes de IA:** criação e experimentação com agentes no Microsoft Copilot Studio, incluindo testes de interpretação de conteúdo e avaliação de respostas.

**Qualidade técnica:** realização de testes de componentes, investigação de falhas e documentação de limitações.

## Estado de desenvolvimento

Os componentes RPA foram desenvolvidos e passaram por atividades de testes e depuração. A validação integral permanece em andamento.

O agente de IA foi criado e testado em ambiente de desenvolvimento, com avaliações adicionais de consistência pendentes.

Não há declaração de implantação em produção.

## Sobre a documentação

Este repositório contém exclusivamente documentação técnica geral, sem código corporativo, dados reais, configurações internas ou informações de terceiros.

Os exemplos conceituais não representam a arquitetura de uma organização específica.
